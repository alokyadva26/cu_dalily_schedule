# Feature Mapping: React Web to Java Swing Desktop

This document outlines all discovered features in the original Next.js/React application (`cu-daily-schedule`), their technical implementation, the proposed Java Desktop equivalent, database dependencies, and implementation status.

| Existing React feature | Existing implementation | Proposed Java implementation | Database dependencies | Status |
|---|---|---|---|---|
| **Landing Screen & Navigation Hub** | `src/app/page.tsx`<br>Displays CU branding, CU logo, two large choice cards (Student NFC & Teacher QR), status footer. | `com.cudailyschedule.ui.LandingScreen`<br>Swing `JPanel` with custom painting for subtle gradient & CU campus watermark, two hoverable interactive action cards, and responsive navigation controller. | None (static routing) | Planned |
| **Student NFC Emulation** | `src/app/page.tsx` (`Link href="/student"`)<br>Simulates NFC badge tap by navigating to student schedule. | `LandingScreen` NFC Card Button / Dialog<br>Simulates NFC tap by entering/selecting Student UID (e.g., `24BCS-101`) or quick-launching default student view. | `students`, `timetables` | Planned |
| **Teacher QR Code Emulation / Scan** | `src/app/page.tsx` (`Link href="/teacher"`) & `QRScanner.tsx`<br>Navigates to teacher search or launches web camera scanner to read employee ID. | `LandingScreen` QR Button & `com.cudailyschedule.ui.TeacherSearchDialog`<br>Interactive modal providing manual Employee ID entry and simulated QR scanner with instant sample selection. | `teachers` | Planned |
| **Student Schedule Timeline** | `src/app/student/page.tsx` & `ScheduleCard.tsx`<br>Renders vertical timeline with time labels, connectors, status dots, subject, faculty, and room. | `com.cudailyschedule.ui.StudentSchedulePanel`<br>Custom Swing component rendering scrollable chronological timeline with styled cards, time nodes, and status indicators. | `timetables`, `schedule_entries` | Planned |
| **Real-time Active Class Detection** | `src/app/student/page.tsx`<br>Compares current system time against class start/end times to mark class as `active`, `next`, or `completed`. | `com.cudailyschedule.service.ScheduleTimingService`<br>Calculates active/next status using `java.time.LocalTime` and `ZoneId.of("Asia/Kolkata")`. | `schedule_entries` | Planned |
| **Interactive Class Details Panel** | `src/components/ClassDetails.tsx`<br>Side panel showing full course name, faculty, classroom, and live circular countdown ring. | `com.cudailyschedule.ui.components.ClassDetailsPanel`<br>Swing panel with details card and custom animated circular countdown meter (`paintComponent`). | `schedule_entries` | Planned |
| **Live Circular Countdown Timer** | `ClassDetails.tsx` (SVG stroke dashoffset animation) | `CircularProgressIndicator.java`<br>Custom Swing `JComponent` with anti-aliased graphics, animated arc, and countdown text. | None (time-based) | Planned |
| **Subject Code to Friendly Name Mapping** | `src/lib/utils.ts` (`subjectMap` dictionary)<br>Maps codes like `24CSP-305` to "Competitive Coding-II". | `com.cudailyschedule.util.SubjectRegistry`<br>Lookup map containing subject code dictionary with raw code fallback. | None | Planned |
| **Weekend / Holiday Empty State** | `src/components/EmptyState.tsx`<br>Festive icon & message ("No Classes Today! Enjoy your day off!"). | `EmptyStatePanel.java`<br>Swing empty state view with illustration, festive greeting, and day-off message. | None | Planned |
| **End of Day View & "View Tomorrow"** | `src/components/EndOfDayState.tsx`<br>Shows "Classes are Over!" and button to load tomorrow's timetable. | `EndOfDayPanel.java`<br>Swing view with "View Tomorrow's Schedule" button switching timeline dataset to next day. | `schedule_entries` | Planned |
| **Teacher Search by Employee ID** | `src/app/teacher/page.tsx`<br>Form input for Employee ID with validation and uppercase normalization. | `TeacherSearchPanel.java`<br>Swing text field with auto-capitalization, validation, search button, and quick-picker buttons. | `teachers` | Planned |
| **Teacher Not Found Error State** | `src/app/teacher/[employeeId]/page.tsx`<br>Error card when employee ID does not exist in database. | `TeacherNotFoundPanel.java`<br>Swing error card with warning icon and "Back to Search" button. | `teachers` | Planned |
| **Teacher Profile Header & Live Timer Widget** | `src/components/teacher/TeacherProfileHeader.tsx`<br>Avatar circle, name, department, and live timer ("CLASS ENDS IN" / "NEXT CLASS IN"). | `TeacherProfileHeaderPanel.java`<br>Swing header bar with circular avatar, metadata labels, and dynamic live timer badge. | `teachers`, `schedule_entries` | Planned |
| **Teacher Schedule View & Split Panel** | `src/components/teacher/TeacherScheduleView.tsx` & `TeacherScheduleCard.tsx`<br>Two-column layout: left timeline, right dynamic status panel. | `TeacherSchedulePanel.java`<br>Two-column Swing layout featuring timetable on the left and sticky status card on the right. | `teachers`, `schedule_entries` | Planned |
| **Auto-refresh & Manual Refresh** | `src/components/BottomCard.tsx`<br>Displays last updated time and refresh trigger. | `FooterStatusPanel.java`<br>Swing footer showing last refresh timestamp and a "Refresh" button executing async query. | All tables | Planned |
| **PostgreSQL Database Connectivity** | `src/lib/supabase.ts` & `src/lib/db.ts`<br>Supabase client queries via PostgREST. | `com.cudailyschedule.config.DBConnection` & `DAO Layer`<br>Pure JDBC connection using `org.postgresql.Driver` with SSL and connection parameters. | Supabase PostgreSQL | Planned |
| **Timetable Management & CRUD Operations** | DDL in `schema.sql` (Timetables, Teachers, Students, Schedule Entries). | `TimetableDAO`, `TeacherDAO`, `StudentDAO`, `ScheduleEntryDAO`<br>Complete CRUD methods (`findById`, `findByEmployeeId`, `create`, `update`, `delete`). | All tables | Planned |
| **Schedule Administration Screen (College CRUD)** | Derived from database schema capabilities in `schema.sql`. | `com.cudailyschedule.ui.AdminScheduleDialog`<br>Management dialog for adding/editing schedule entries and testing cross-app data persistence. | All tables | Planned |
